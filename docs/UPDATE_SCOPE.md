# Publication update scope

The original numerical implementation and configuration files are unchanged.
Original provenance remains in SOURCE_COMMIT.txt. Presentation updates derive
from research commit 72ee1cb; the subsequent full-domain records carry source
file hashes in data/full_domain/PROVENANCE.json.

The full-domain material is a frozen-result verification supplement, not a
rerunnable version of the later candidate search. Its settings file documents
that experiment and is not an input for the original experiment entry point.
The original and subsequent results must not be combined into a single
structure-recovery rate or a single-factor coverage ablation.

Cavern field values are copied exactly from the retained six-MPa calculation.
No solver binaries, save states, request logs, manuscript files or generated
figure files are included.
